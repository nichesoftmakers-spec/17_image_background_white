# 【Windows専用】ImageBackgroundWhite GUI ｜ EC商品写真 輪郭自動抽出・純白背景化＆自然影合成機

> **「Amazonや楽天市場に出品したいけれど、商品写真の背景を1枚ずつPhotoshopで白抜き切り抜きするのが大変すぎる…」**  
> **「Web上の無料切り抜きツールは、未公開の新商品や顧客の注文写真をクラウドにアップロードするのが情報漏洩的に怖い…」**  
> **「白背景にしただけだと商品が空中に浮いて見えて不自然…自然な影を手軽に入れたい…」**

『ImageBackgroundWhite GUI』は、ECサイト運営者・物販セラー・オークション出品者のために開発された、**ドラッグ＆ドロップだけで商品写真を自動認識し、モール推奨の「純白背景（#FFFFFF）」または「透過PNG」に一発変換した上で、プロ級のリアルな接地影（ドロップシャドウ）を合成できるWindows専用ポータブルGUIツール**です。

面倒なインストール作業やPython環境の構築は一切不要。解凍してダブルクリックするだけですぐに使えます。

## 📌 本ツールが「得意なこと」と「適さないケース」（ご購入前の確認）

お客様に安心してご利用いただくため、本ツールの得意なシチュエーションと適さないケースを明確に記載しております。

### ✅ 本ツールが得意なこと（推奨環境）
1. **撮影ブース・背景紙・単色布の前で撮影された商品写真**
   - 白、グレー、黒、木目など、背景がある程度均一な写真であればプロ級のクオリティで一発切り抜きできます。
2. **白い服・白いスニーカー・白箱などの商品**
   - 「外周接続解析」により、商品の内側にある白色が透けて穴があくことはありません。
3. **底面のある物販商品（ボトル、靴、コスメ、ガジェット、箱など）**
   - 自動算出される「接地影（コンタクトシャドウ）」により、スタジオ撮影のような自然な床置き感が手に入ります。
4. **大量写真の超高速バッチ処理**
   - 外部サーバーとの通信を待たずに、1枚あたり0.1秒前後で数百枚の写真を一括処理できます。
5. **機密・未公開新商品の写真処理**
   - 外部通信ゼロの完全ローカル処理のため、社外秘データや新商品写真も情報漏洩リスク0%で安全に処理できます。

### ⚠️ 本ツールが適さないケース（苦手なシチュエーション）
1. **散らかった部屋の室内写真や複雑な風景写真**
   - 背景に家具や本棚、雑多なものが写り込んでいる場合、輪郭を自動分離できません（簡易的な背景紙や布の前での撮影が必要です）。
2. **背景と被写体の色が「完全同一」で境界の陰影差がゼロの場合**
   - 例：真っ白の背景紙の前に置いた真っ白の無地ダンボール（境目の色差がない部分）。
3. **極めて細い人物の毛髪や、透明ガラスの屈折透過**
   - 数GBのAIモデルによる髪の毛1本ずつの抽出や、透明グラスの背景透過には対応していません（クッキリした輪郭の物販写真に特化しています）。

## 💡 このツールで解決できるお悩み

- **ECモール規定の「純白背景（#FFFFFF）」へ一括自動変換**:
  - Amazon、楽天市場、Yahoo!ショッピング、Shopify等の規約に準拠した完全な「純白背景（RGB 255, 255, 255）」のJPEG画像と、加工素材として重宝する「透過PNG」を同時に一括生成します。
- **外周接続解析（Flood-fill）による誤透過防止**:
  - 単純な色抜きソフトで起きがちな「白いシャツや白い箱の内側まで透けて穴があいてしまう」事故を物理的に防止。画像の外周から接続している背景のみを正確に判別・除去します。
- **ワンクリックで選べる自然な影合成（接地影／背面シャドウ）**:
  - `[ 👞 接地影（足元の自然な影） ]`: ボトル、靴、化粧品、箱モノなど、床面に置かれているようなリアルな足元影を自動合成。
  - `[ 👕 背面シャドウ（ふんわり影） ]`: アパレルや雑貨向けに、斜め後方に柔らかく落ちる高級感あるドロップシャドウを合成。
  - `[ 影なし（フラット切り抜き） ]`: カタログ風のフラットな切り抜きも自由自在。
- **輪郭フリンジ除去（黒ずみ境界線自動クレンジング）**:
  - 背景を白に切り替えた際、商品の輪郭に残りがちな「撮影時の薄暗い背景（1〜2pxの黒ずみ・影）」を内側に微小収縮して綺麗に消去。Photoshopのプロ仕上げのような美しいエッジを実現します。
- **Amazon・楽天推奨の「85%中央配置＆余白最適化」**:
  - 「商品が画面の85%以上を占めること」というモールの掲載基準にワンクリックで自動フィット。被写体を中央に揃えて理想的な余白バランスに自動補正します。

## 🛠️ 主な機能・特徴（ボタン切り替え式UI）

1. **影合成プリセット（3択）**
   - ◎ `👞 接地影（足元の自然な影）`【推奨・物販向け】
   - ○ `👕 背面シャドウ（ふんわり影）`【アパレル・雑貨向け】
   - ○ `影なし（フラット切り抜き）`
2. **背景カラー選択**
   - ◎ `⚪ 純白（#FFFFFF / ECモール推奨）`
   - ○ `🎨 薄灰色（#F8F9FA / 上品な展示）`
3. **自動補正トグル**
   - ☑ `✂️ 輪郭フリンジ除去（黒ずみ境界線の自動クレンジング）`（デフォルトON）
   - □ `🎯 Amazon/楽天推奨（85%中央配置＆余白最適化）`
4. **安心の同時出力**
   - 高品質JPEG（白背景・画質95）
   - 透過PNG（背景透過素材）
   - 処理結果の一括ZIP保存（`ImageBackgroundWhite_Results.zip`）

## 🚀 使い方（3ステップで完了）

1. **写真の投入**
   - 画面中央のアップローダーに、処理したい商品写真（PNG, JPG, JPEG, WEBP, BMP）をドラッグ＆ドロップします。
2. **仕上がりオプションの確認**
   - 必要に応じて「影合成プリセット」「輪郭フリンジ除去」「85%中央配置」をボタンで切り替えます（迷った場合はデフォルトのままで最も綺麗に仕上がります）。
3. **実行とダウンロード**
   - 「✨ ○枚の写真を純白背景化＆影合成する」をクリックします。
   - 処理完了後、Before/Afterプレビューで仕上がりを確認し、「📦 全○枚の処理結果を一括ZIPダウンロード」をクリックして保存します。
